# ProxDeck releases

Download links for the ProxDeck client software. This repository holds release
files only. It has no source code.

The clients work with ProxDeck services that you or your organization are
authorized to use.

## Downloads

Go to [Releases](../../releases). Each release lists these files:

| Client | File |
| --- | --- |
| VS Code extension | `proxdeck-vscode-<version>.vsix` |
| OpenCode plugin | `proxdeck-opencode-<version>.tgz` |
| OpenChamber extension | `proxdeck-openchamber-<version>.zip` |

Releases are published by ProxDeck's build pipeline. Do not install files from
anywhere else.

## Install

Install steps for each client will be added with the first release.
